# Calculator

## About the Project
Calculator is a simple application designed to perform basic mathematical calculations. It provides an easy way to perform arithmetic operations and demonstrates fundamental programming concepts.

## Features
Addition
Subtraction
Multiplication
Division
User input handling
Clear and simple interface

## Technologies Used
Java
Object-Oriented Programming (if implemented)
VS Code

## Operations
 Operation | Description |

 Addition (+) : Adds two numbers 
 Subtraction (-) : Subtracts one number from another 
 Multiplication (*) : Multiplies two numbers
 Division (/) : Divides one number by another 

## How to Run

### Requirements
Java Development Kit (JDK), if using Java
VS Code or another Java-compatible editor

### Steps
1. Clone or download this repository.
2. Open the project folder in your editor.
3. Compile the Java file using `javac Calculator.java`.
4. Run the program using `java Calculator`.

*Replace `Calculator.java` and the commands above if your filename or programming language is different.*
